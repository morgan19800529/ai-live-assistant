# ai-live-assistant

> V2 · AI 直播助手 —— 输入主题，生成带留人节点、可直接进提词器的直播稿。Morgan AI Studio 产品线。

## 在线使用
👉 **https://morgan19800529.github.io/ai-live-assistant/ai-live-assistant.html**

手机浏览器打开即可。纯前端、不上传、不存密钥。

## 怎么用
1. 填：主题 / 时长 / 平台 / 受众 / 目标 CTA / 风格
2. 点「生成 Prompt」→ 一键复制
3. 粘给任意 AI（ChatGPT / Claude / 豆包 / Kimi）出稿
4. 人工过一遍（删掉不像自己说话的句子、核对例子真实）
5. TXT / Markdown 导入「镜头说」提词器开播
6. 直播后把留人点效果记进复盘，回流下次选题
